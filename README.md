# AI:VERSE 프론트엔드

무채색에서 살아남기 부스용 화면입니다. 운영자가 서면 동의를 확인한 뒤 참가자를 시작 화면으로 안내합니다. 참가자는 포토박스에서 촬영한 뒤 분석 결과를 보고, QR로 결과를 받거나 진단천과 가상 메이크업을 체험할 수 있습니다.

## 부스 컴퓨터에서 실행

기존 백엔드를 8000번 포트에서 실행합니다. 기본 로컬 합성으로 점검할 때는 `AI_VERSE_BE` 폴더에서 별도 `.env` 없이 기본 설정으로 실행할 수 있습니다.

```powershell
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

프론트 폴더를 열고 별도 창에서 아래 명령을 실행합니다.

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

Chrome에서 [시작 화면](http://localhost:5173/1.html)을 엽니다. 촬영 버튼을 누르면 프론트가 먼저 [백엔드 상태](http://localhost:8000/health)를 확인합니다. 서버를 시작한 뒤 같은 버튼으로 재시도할 수 있습니다. 별도 환경 설정을 사용하는 경우 CORS 값은 JSON 배열이어야 합니다. 예시는 `CORS_ORIGINS=["http://localhost:5173"]`입니다.

## 카메라와 백엔드 없이 테스트

Chrome에서 `2.html`을 직접 열거나 [촬영 화면](http://localhost:5173/2.html)으로 이동합니다. 화면 위쪽의 **테스트로 촬영 건너뛰기**를 누르면 예시 결과, 메이크업 비교, 결과 카드를 확인할 수 있습니다. QR 이미지를 보려면 프론트 서버에서 화면을 엽니다.

행사용 버전에서는 `2.html`의 `<body>`에서 `data-test-mode`를 제거하면 촬영 화면에서 테스트 버튼이 숨겨집니다.

## 휴대폰 QR 확인

행사에서는 휴대폰과 부스 컴퓨터 양쪽에서 열 수 있는 HTTPS 주소에 이 폴더를 올리고, 같은 주소의 `/api/`와 `/health`를 기존 백엔드로 전달합니다. 프론트가 QR에 해당 주소의 결과 카드 링크를 넣습니다. 결과 카드는 기존 공유 토큰 API를 사용하며 얼굴 사진은 표시하지 않습니다.

`localhost`에서 만든 QR은 부스 컴퓨터에서 확인할 수 있습니다. 화면에 표시되는 최대 공유 시간은 QR 만료와 분석 만료 중 더 빠른 시각입니다. 다음 참가자로 초기화하면 브라우저의 분석 세션만 지웁니다. 사진 보관과 공유 링크 만료는 기존 백엔드 설정을 따릅니다.
